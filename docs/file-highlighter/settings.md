# Customization & Controls

The **File Highlighter** window brings asset activity tracking, highlight timing, and folder styling into a unified interface without cluttering your Unity workspace.

---

## Activity View

When new files are imported or removed, the main view lists all active items:

- **Item Hierarchy:** Displays folders and files with visual indentation lines showing the exact project folder tree.
- **Ping & Explorer:** Click **Ping** to focus the item in the Project window, or click **Explorer** to open its folder in Windows File Explorer.
- **Status Tags:** Displays green `ADD` tags for newly imported files and red `DEL` tags for removed assets.
- **Footer Bar:** Shows live counts for added and deleted items, a **Hide** button to dismiss until manually opened, and the **Settings** button.

---

## Settings View

Click the **Settings** button in the footer to open configuration panels:

### Highlight Options
- **Duration:** Adjust how many seconds highlights stay visible before fading out.
- **Add Color:** Choose the signature highlight color for imported assets.
- **Delete Color:** Choose the highlight color for deleted assets.
- **Reset:** Restore default highlight durations and colors.

### Folder Color Studio
- **Target Folders:** Shows the folders currently selected in the Project window.
- **Quick Palette:** Click any of the 12 signature color buttons to instantly style the selected folders.
- **Custom Color & Badges:** Use the color picker for custom hex tones, or enter text tags like `FOX`, `TEX`, `MAT`, or `ANIM`.
- **Apply to Subfolders:** Toggle whether child folders inherit the selected folder styling automatically.

### Colored Folders Management
- **Search Filter:** Filter your styled folders by path name.
- **Quick Ping:** Click any folder row in the list to highlight it directly in the Project window.
- **Subfolder Toggle:** Enable or disable subfolder inheritance per folder.
- **Clear All:** Reset all folder color customizations with a safety confirmation prompt.

### Display Settings
- **Tint Folder Icons:** Toggle folder icon coloring and adjust tint opacity.
- **Row Background Tint:** Toggle full row background tinting and set opacity.
- **Accent Stripe:** Toggle left accent stripe and configure stripe thickness.
- **Badges:** Toggle text badge pills on styled folders.
