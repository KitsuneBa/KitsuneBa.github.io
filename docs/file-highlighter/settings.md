# Customization & Controls

The **File Highlighter** window brings asset activity tracking, highlight configuration, and folder styling into a unified interface without cluttering your workspace.

---

## 🎛️ Activity View

When new files are imported or removed, the main view lists all active items:

* **Item Hierarchy:** Displays folders and files with visual indentation lines showing project structure.
* **Ping & Explorer:** Click **Ping** to focus the item in the Project window, or click **Explorer** to open its folder in File Explorer.
* **Status Badges:** Shows green `ADD` tags for added files and red `DEL` tags for deleted files.
* **Footer Bar:** Shows live count for added and deleted items, a **Hide** button to dismiss until manually opened, and the **Settings** button.

---

## ⚙️ Settings View

Click the **Settings** button in the footer to open the configuration panels:

### Highlight Options
* **Duration:** Adjust how many seconds highlights stay active before beginning to fade out.
* **Add Color:** Pick the signature highlight color for imported assets.
* **Del Color:** Pick the highlight color for deleted assets.
* **Reset (`R`):** Restore default highlight duration and colors.

### Folder Color Studio
* **Target Folders:** Shows folders currently selected in the Project window.
* **Quick Palette:** Click any of the 12 signature color buttons to instantly style the selected folders.
* **Custom Color & Badges:** Use the color picker for custom hex tones, or enter text and emoji tags like `★`, `FOX`, `TEX`, `MAT`, or `ANIM`.
* **Apply to Subfolders:** Toggle whether subfolders inherit the selected folder styling automatically.

### Colored Folders List
* **Search Filter:** Filter your colored folders by path name.
* **Quick Ping:** Click any folder row in the list to ping it directly in the Project window.
* **Subfolder Toggle:** Enable or disable subfolder inheritance per folder.
* **Clear All:** Reset all folder color customizations with a safety confirmation button.

### Display Settings
* **Tint Folder Icons:** Toggle folder icon coloring and adjust tint opacity.
* **Row Background Tint:** Toggle full row background tinting and set opacity.
* **Accent Stripe:** Toggle left accent stripe and configure stripe thickness.
* **Badges & Emojis:** Toggle badge pills on styled folders.
