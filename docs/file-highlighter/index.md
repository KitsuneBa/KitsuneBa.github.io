# File Highlighter

**File Highlighter** combines automatic import tracking with native folder styling directly in the Unity **Project Window**. It highlights newly imported, moved, and deleted assets so you never lose track of unpacked files, while letting you color-code and organize project folders with custom colors, accent bars, and emoji badges.

---

## 🛠️ How It Works

1. **Import Tracking:** Whenever you import a package, move assets, or delete files, File Highlighter tracks affected items and highlights them in the Project window with smooth fade-out timers.
2. **Folder Styling:** Right-click any folder or group of folders in the Project window to apply color presets, set custom colors, assign badges, or toggle subfolder inheritance.
3. **Companion Window:** Access recent import activity and the Folder Color Studio from a single window via **Tools → 🦊KitsuneBa's Tools🦊 → 🦊File Highlighter🦊**.

---

## ✨ Key Features

* **Project Window Overlays:** Highlights newly imported files and their parent folder chain so you can trace files from `Assets/` down to the exact asset.
* **Native Folder Painter:** Style folders with background tints, accent stripes, custom icons, and tag badges directly in Unity.
* **Context Menu Presets:** Right-click folders in the Project window to instantly apply colors like Purple, Red, Orange, Lime, Cyan, or Rose.
* **Click-to-Ping Navigation:** Click any item row or its Ping button in the File Highlighter window to locate and select the folder or file in the Project window.
* **Hover-to-Pause Timer:** Hovering the mouse over the File Highlighter window pauses the fade-out timer so highlights stay active while you inspect them.
* **Subfolder Inheritance:** Choose whether subfolders automatically inherit their parent folder color or keep their own distinct styling.
