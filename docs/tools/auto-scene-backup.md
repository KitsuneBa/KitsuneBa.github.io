# Auto Scene Backup

:::note Work in Progress
This tool documentation is currently being prepared. Check back soon for the full guide and release details!
:::

**Auto Scene Backup** is a lightweight Unity editor extension designed to prevent work loss while modifying VRChat avatars and worlds.

---

## ⚡ Overview
* Automatic interval backups while you work in Unity.
* Quick recovery points before applying major avatar changes or merges.
* Zero external dependencies.

---
