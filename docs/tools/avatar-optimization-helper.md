# Avatar Optimization Helper

:::note Work in Progress
This tool documentation is currently being prepared. Check back soon for the full guide and release details!
:::

**Avatar Optimization Helper** assists avatar creators in analyzing, troubleshooting, and improving their avatar's performance rank in VRChat.

---

## ⚡ Overview
* Identifies excessive material slots, skinned mesh renderers, and PhysBones components.
* Provides non-destructive tips to help hit *Good* or *Medium* performance ratings.
* Streamlines cleanup before uploading.

---
