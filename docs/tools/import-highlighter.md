# Import Highlighter

:::note Work in Progress
This tool documentation is currently being prepared. Check back soon for the full guide and release details!
:::

**Import Highlighter** is a Unity project management tool that helps you locate and organize newly imported assets, textures, and prefabs in large avatar projects.

---

## ⚡ Overview
* Visually highlights recently added assets in your Project window.
* Helps keep your asset folders organized when importing multiple clothing packages or accessories.
* Simple one-click filter view.
