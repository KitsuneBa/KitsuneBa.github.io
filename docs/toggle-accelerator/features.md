# Features & Workflows

Learn how **Toggle Accelerator** streamlines your avatar setup in Unity.

---

## 🎯 Key Features

### 1. Instant Component Setup
Quickly add toggle logic directly from the Unity inspector without manually opening the animator or recording animation clips for simple on/off states.

### 2. Dual Support: VRCFury & Modular Avatar
Whether your avatar is configured using **VRCFury** components or **Modular Avatar** prefabs, Toggle Accelerator adapts to your preferred non-destructive workflow.

### 3. Clean Hierarchy & Non-Destructive
* Works at build time without permanently altering your base avatar assets.
* Easy to remove, rename, or reorganize at any time.

### 4. Smart Naming & Menu Organization
Automatically formats parameter and menu names based on the target GameObject to save time typing.
