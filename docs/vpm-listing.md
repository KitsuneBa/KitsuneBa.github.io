# Adding the VPM Listing

You can easily add the **KitsuneBa's Tools** repository to your VRChat Creator Companion (VCC) or ALCOM package manager.

---

## ⚡ Method 1: One-Click Add (Recommended)

If you are browsing on the computer where VCC or ALCOM is installed:

<p>
  <a className="button button--primary button--lg" href="vcc://vpm/addRepo?url=https://kitsuneba.github.io/KitsuneBaTools/index.json" style={{ textDecoration: 'none' }}>
    🦊 Add to VCC / ALCOM
  </a>
</p>

Your browser will ask for permission to open the VCC or ALCOM application. Click **Open**, and the client will prompt you to confirm adding **KitsuneBa's Tools**.

---

## 📋 Method 2: Manual Add in VCC

If the 1-click link does not open:

1. Copy the repository URL:
   ```text
   https://kitsuneba.github.io/KitsuneBaTools/index.json
   ```
2. Open **VRChat Creator Companion (VCC)**.
3. Go to **Settings** (gear icon on the bottom left).
4. Select the **Packages** tab.
5. Click **Add Repository** in the top right.
6. Paste the URL into the input field and click **Add**.

---

## 🌊 Method 3: Adding via ALCOM

1. Copy the repository URL:
   ```text
   https://kitsuneba.github.io/KitsuneBaTools/index.json
   ```
2. Open **ALCOM**.
3. Go to **Settings** &rarr; **Repositories**.
4. Click **Add Repository**.
5. Paste the listing URL and confirm.

---

## 🔄 Updating Packages

Once the repository is added, any new updates released to **Toggle Accelerator** or upcoming tools will automatically appear in your package manager list with an **Update** button.
