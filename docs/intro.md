# KitsuneBa's Tools

A collection of lightweight Unity utilities created to make building, optimizing, and organizing VRChat avatars faster, cleaner, and less tedious.

All tools are distributed as non-destructive VPM packages that integrate directly into the VRChat Creator Companion (VCC) and ALCOM.

---

## Method 1: One-Click Installation

The simplest way to install and keep these tools updated is through the **VRChat Creator Companion (VCC)** or **ALCOM**.

Click the button below to add the repository to your package manager:

<div style={{ display: 'flex', alignItems: 'center', margin: '1.25rem 0' }}>
  <a className="button button--primary button--lg" href="vcc://vpm/addRepo?url=https://kitsuneba.github.io/KitsuneBaTools/index.json">Add Repository to VCC / ALCOM</a>
</div>

Your browser will ask for confirmation to open your package manager. Click **Open**, and then confirm adding **KitsuneBa's Tools**.

---

## Method 2: Manual Setup in VCC

If the one-click link does not open automatically in your browser:

1. Copy the repository URL:
   ```text
   https://kitsuneba.github.io/KitsuneBaTools/index.json
   ```
2. Open **VRChat Creator Companion (VCC)**.
3. Click **Settings** in the bottom-left corner.
4. Select the **Packages** tab.
5. Click **Add Repository** in the top-right corner.
6. Paste the URL into the input field and click **Add**.

---

## Method 3: Adding via ALCOM

If you use ALCOM as your package manager:

1. Copy the repository URL:
   ```text
   https://kitsuneba.github.io/KitsuneBaTools/index.json
   ```
2. Open **ALCOM**.
3. Navigate to **Settings -> Repositories**.
4. Click **Add Repository**.
5. Paste the URL and confirm the addition.

---

## Keeping Packages Updated

Once the repository is added to your project, any new releases, bug fixes, or performance improvements will appear directly in your project's package list with an **Update** button.

---

## Compatibility & Requirements

All tools are built and tested for standard VRChat avatar creation setups:

- **Unity:** 2022.3.22f1
- **VRChat Avatar SDK:** 3.7.0 and newer
- Fully compatible with modern non-destructive frameworks including **VRCFury**, **Modular Avatar**, and **NDMF**
